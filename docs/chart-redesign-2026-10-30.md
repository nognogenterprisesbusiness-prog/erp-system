# Existing chart redesign — 30 October 2026

Reference: the custom SVG charts in the user-provided `D:/Client-Project/handoff` prototype. The ERP retains its existing line chart for monthly expenses, area chart for material consumption and donut for posted project costs. No prototype backend, global styling, mock data or chart dependency was copied.

After the user's feedback that the initial styling was too similar, the chart renderer was rebuilt around pixel-measured custom SVG. Trend charts now use Fritsch–Carlson monotone cubic paths, stronger gradient fills, active-point halos, pill legends and floating dark tooltips with tap/keyboard pinning and dismissal. Month summaries use the same plotted values (currency total or quantity in the selected unit). Units remain separate; the existing unit picker stays available. The ResizeObserver is disconnected on unmount. Axis labels and strokes no longer shrink with an SVG viewBox at phone width. Theme-specific colors support the existing blue and charcoal themes. Scale geometry preserves zero, small fractional values and negative net values; a single month is centered.

The project donut uses custom rounded annular paths with gaps and radial lift on highlight, rather than the earlier dashed-circle implementation. It preserves the posted-cost denominator and category amounts. Small slices have clamped corners/gaps; a single category is a complete ring. Segments and a compact list legend highlight together, with percentage and amount labels. Null categories remain “Not posted.” The legend stacks below the ring in narrow cards through a container query rather than relying on viewport width. Reduced-motion preferences are respected.

No queries, cost postings, permissions, financial calculations, migrations or mobile code changed. New chart interaction state affects presentation only.
