# User manual and workflow verification — 9 October 2026

The User manual now has its own authenticated documentation area at `/manual`, outside the ERP workspace shell. Each topic has a `/manual/[topic]` URL, grouped search navigation on the left, a readable article and an active On this page outline on the right. Mobile uses collapsible Browse the user manual and On this page controls. Previous/next guide links follow the role-filtered order. The ERP sidebar retains the User manual label and position and opens the new route. `/help`, its query and old topic bookmarks redirect to a permitted guide; invalid or unauthorized old bookmarks fall back to Quick start.

The 19 topics cover quick start, all five roles, setup/assignments, projects/documents, employees, warehouses, suppliers, inventory, requests, shortages, supplier purchasing, receiving, site purchases, assets, attendance/reports, billing/costs, audited corrections, mobile compatibility and troubleshooting. The server filters both navigation and article access by role; direct unauthorized topics use Guide unavailable. The manual distinguishes the Admin owner gate above ₱50,000 from Engineer request review and required Admin/Finance site-purchase review. Request and quotation links remain optional for supplier purchases. Inspection, receipt, payment and actual consumption are separate actions.

Seventeen actual empty-form crops illustrate projects/client contact fields, warehouse identity, suppliers, employees, equipment, vehicles, daily reports, material catalog, purchase lines, site purchase receipt/items/payment source, invoice fields, requests, unavailable materials and the city selection control. All names, contacts and addresses visible in these crops are the app's input examples, not entered or saved client records. Numbered boxes, written captions and a keyboard-accessible native full-size preview explain the fields. The WebP assets total about 93 KB and contain no credentials, client records, balances, financial postings or receipt photos. Full source screenshots are excluded from the repository and removed after cropping. Images use the existing Next image pipeline with fixed dimensions and responsive sizing; no dependency was added.
